
  # Vehiglass Website

  This is a code bundle for Vehiglass Website.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  ## Éditer le contenu avec Pages CMS

  Le contenu éditorial du site est défini dans `src/content/site.json` et les champs
  disponibles sont décrits dans `.pages.yml`. Les images ne sont pas modifiables
  depuis Pages CMS.

  1. Publier les fichiers sur la branche `main` du dépôt GitHub.
  2. Ce connecter sur [Pages CMS](https://app.pagescms.org/) avec un compte GitHub qui a accès au dépôt.
  3. Ouvrir le dépôt Vehiglass : les rubriques éditables apparaissent dans le menu.
  4. Inviter une personne par email depuis la gestion des collaborateurs Pages CMS.
